# Contributing

NOTacMap is a hobby project that one person looks after in their free time. Every report and idea helps, and you don't need to write code to take part. If something you tell me ends up in the mod, your name goes with it.

## Reporting a bug

Use the bug form (Issues, then New issue). The more of it you fill in, the quicker it gets fixed: the NOTacMap version, what you did, and the lines with "NOTacMap" from `BepInEx/LogOutput.log`. Please don't paste your phone link or QR code, because it holds the secret that opens your map.

## Ideas and questions

Start a discussion in the Discussions tab. I read every idea, and I can't promise each one gets built. If yours does, you get named in the changelog and in the release notes, so everyone can see it came from you. That is how the last bug fix credited the person who found it. If you'd rather stay unnamed, just say so.

Not sure it's good enough to post? Post it anyway. Some of the best things in a project start as "this is probably a silly idea".

## Security problems

Please don't post these publicly. Follow [SECURITY.md](SECURITY.md) and report it privately.

## Sending code

If you want to fix or add something yourself, thank you. Open an issue or a discussion first and tell me what you plan. Small, focused changes are easiest to look at. The README explains how to build the plugin ("To build from source").

By sending a change you agree that it is released under the project's [MIT license](LICENSE).
